# 🪨 Stone Paper Scissors Game

An interactive Stone-Paper-Scissors game built using Python and Streamlit, featuring computer-generated moves and score tracking.

## 🚀 Live Demo

[Play the game online](https://stonepapersciappr-e5jseusxyo39nnrytoryjt.streamlit.app/)

## 🛠️ Technologies Used
- Python
- Streamlit
- Random module

## ✨ Features
- Interactive game interface
- Random computer moves
- Win, loss, and draw detection
- Score tracking

## 💻 Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Akshatjain956/stone_paper_scissor.git
   ```
2. Open the project folder:
   ```bash
   cd stone_paper_scissor
   ```
3. Install dependencies:
   ```bash
   python -m pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   python -m streamlit run stonepaper.py
   ```
